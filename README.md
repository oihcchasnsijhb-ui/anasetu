# AnnaSetu

A mobile-first food rescue and redistribution platform prototype.

## Features

- Demo phone/OTP login and role onboarding
- Donor dashboard and donation posting
- Nearby donation discovery and claiming
- Volunteer delivery tracking experience
- NGO receiver workflow
- Impact analytics and leaderboard
- English/Hindi interface toggle
- Responsive PWA-ready interface

## Run locally

Serve the repository with any static server:

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

> This repository currently provides an interactive front-end prototype using local mock data. Production OTP, authentication, database, GPS, traffic APIs, payments and push notification services must be connected before real deployment.
